I build **reliable, scalable backend systems** with **Kotlin**, **Spring**, Scala, Python, and Terraform. But when the working day is over, I return to my favourite playground: **Lisp and GNU Guile Scheme**.

I enjoy building things from the ground up. My personal projects include a language server, Lisp formatter/linter,  CI/CD orchestrator, a CMS, a project management platform, a web crawler, a programming language toolkit, a Wayland dock, and even my GNU/Linux system configuration.

Outside the digital world: CrossFit, guitar, and occasionally wondering whether I can automate my garden with Lisp.

I believe in **software freedom, simplicity, extensibility, reproducibility, and the joy of understanding how things work**. Naturally, I use Emacs, live in the terminal, and have remapped Caps Lock to Control. Some habits are irreversible.
